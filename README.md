### Финальное задание 8 спринта

#### Задание

##### Реализация сервиса отслеживания посылок со следующими функциями:

- регистрация посылки,
- получение списка посылок клиента,
- изменение статуса посылки,
- изменение адреса доставки,
- удаление посылки.

##### Реализация тестирования сервиса

Для тестирования добавлена функция 
```go
createTable(db *sql.DB, t *testing.T)
```

для создания таблицы в базе данных в памяти - для сохранения чистоты базы.

и функция
```go
setupTest(t *testing.T) (*sql.DB, ParcelStore, Parcel)
```
для повторного использования в тестирующих функциях.
